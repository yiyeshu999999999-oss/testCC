# Marisol Bay · 玛丽索尔湾

一个原创的低多边形海滨城市开放世界 Demo，用 Three.js（r160）编写，单个 HTML 文件，没有构建步骤。

## 运行

直接用浏览器打开 `index.html` 即可（需要联网，从 jsDelivr 加载 Three.js 和 Google Fonts）。
如果浏览器限制 `file://`，可以在本目录启动一个静态服务器：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 内容

| 系统 | 说明 |
|---|---|
| 城市 | 8×7 个街区的程序化生成城市（固定随机种子，每次都一样）：市中心高楼、海滨酒店带装饰艺术风格的竖向装饰条和霓虹招牌、低层粉彩建筑、4 座公园（带喷泉） |
| 海滨 | 滨海大道、步行道、沙滩（遮阳伞、救生塔）、带摩天轮的观光码头、红白灯塔（夜间旋转光束）、海上帆船、波浪海面 |
| 角色 | 第三人称低多边形角色，可步行、冲刺、跳跃，能在浅水里涉水 |
| 车辆 | 5 种车型（轿车、跑车、敞篷车、冲浪面包车、皮卡），街机式漂移物理、手刹、碰撞反弹；可以开停着的车，也可以抢正在路上行驶的车 |
| 交通 | 28 辆 NPC 车按右行规则沿道路网行驶、在路口随机转弯、遇到前车和行人会减速刹停 |
| 行人 | 56 个行人沿街区人行道和海滨步道行走，车辆冲过来时会躲闪 |
| 昼夜 | 约 12 分钟一个昼夜循环：日出、正午、日落、星空；夜间窗户、路灯、招牌、摩天轮彩灯会亮起，驾驶时车头灯照亮前路 |
| 玩法 | 快递任务：到珊瑚色光柱取件，限时把包裹送到青色光柱处，剩余时间越多奖励越高 |
| 界面 | 随视角旋转的小地图（标出车辆和任务点）、街道名显示、时钟、速度表、合成音效（引擎、海浪、喇叭） |
| 移动端 | 触屏虚拟摇杆、右半屏拖动视角、上下车、跳跃/手刹、冲刺、喇叭按钮 |

## 操作

| 状态 | 按键 |
|---|---|
| 步行 | `WASD` 移动 · `Shift` 冲刺 · `空格` 跳跃 · `F` 上车 / 抢车 |
| 驾驶 | `W`/`S` 油门 · 刹车倒车 · `A`/`D` 转向 · `空格` 手刹漂移 · `H` 喇叭 · `F` 下车 |
| 通用 | 鼠标转动视角（点击画面锁定鼠标） · 滚轮缩放 · 按住 `T` 加速时间 · `M` 静音 |

## 代码结构

全部逻辑都在 `index.html` 的 `<script type="module">` 里，按以下几部分组织：

- **世界布局常量**：网格尺寸、道路、海岸线、码头位置、街道名
- **碰撞**：二维均匀网格加速的圆形与 AABB 碰撞，外加给相机用的三维射线检测
- **世界生成**：建筑按颜色合并成网格以减少绘制调用；装饰件、路标、路灯、棕榈树都用 InstancedMesh
- **天空与光照**：自定义渐变天空着色器，按关键帧插值天空颜色和太阳，阴影相机跟随玩家
- **车辆**：自行车模型转向，加上横向抓地力衰减来实现漂移
- **交通**：沿车道点做纯追踪，加上前方遮挡检测和防死锁计时
- **任务、HUD、音频、触屏输入**

`window.marisol` 暴露了少量内部状态，方便在控制台调试，例如 `marisol.state.time = 21` 可以直接跳到夜晚。

所有城市、角色、招牌名称和美术都是原创的，没有使用任何现有游戏的素材。
